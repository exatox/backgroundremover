Processing

ModelGeneral works for most subjects. High detail is best at cables, hair and gaps inside the subject. People is tuned for portraits. Lightweight trades quality for speed.
DeviceAuto uses the GPU when one is available.
PrecisionFor the High detail model. Half uses about half the GPU memory and is faster, with practically identical results; Full runs the calculations in 32-bit. The other models and the CPU always use full.
Free GPU memory when idleRelease the model after this long without processing. It reloads by itself on the next image, which then takes a few seconds longer.
Start automaticallyProcess images as soon as they are added. Turn off to queue first and press Start.
Refine edges (alpha matting)Cleaner hair and soft edges. Noticeably slower; the first use takes about a minute to warm up.
Foreground thresholdMask values above this are treated as definite subject.
Background thresholdMask values below this are treated as definite background.
Erode sizeWidth of the uncertain band around the subject edge.
Working sizeLongest side used for matting, in pixels. Higher is sharper and slower.
Hard edgesTurn the soft mask into a crisp cut-off. Good for logos and flat artwork.
Cut-offHigher keeps less of the image.
